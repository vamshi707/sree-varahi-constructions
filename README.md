
# 🏗️ Sree Varahi Constructions

A modern construction services website built to showcase civil, electrical, and smart infrastructure solutions with a clean UI and contact system.

---

## 🚀 About the Project

**Sree Varahi Constructions** is a business website designed to present services like civil construction, electrical works, smart lighting, and CCTV installations.

This project includes:

* 📱 Responsive UI
* 📩 Contact form with EmailJS integration
* 🗺️ Location map integration
* ⚡ Fast performance using Vite + React

---

## 🛠️ Tech Stack

* ⚛️ React (TypeScript)
* ⚡ Vite
* 🎨 Tailwind CSS
* 📧 EmailJS (Contact Form)
* 🧩 Lucide Icons

---

## 📸 Features

* Clean and modern design
* Fully responsive layout (mobile + desktop)
* Working contact form (sends email directly)
* Business contact details (email, phone, location)
* Google Maps integration

## ⚙️ Setup Instructions

### 1. Clone the repository

```
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

### 2. Install dependencies

```
npm install
```

### 3. Run the project

```
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env.local` file in the root:

```
VITE_EMAILJS_SERVICE=your_service_id
VITE_EMAILJS_TEMPLATE=your_template_id
VITE_EMAILJS_PUBLIC=your_public_key
```
